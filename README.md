# Skills_Claude

Инструкции агентов конвейера «Штаб» — общие для любых проектов: о конкретном проекте агент узнаёт из его `CLAUDE.md`, раздел «Для конвейера».

- `agents/executor.md` — исполнитель: берёт issue с меткой `готово` и доводит его до PR с отчётом; сливает только человек.

Правки — только PR-ом, сливает владелец.
